# FoundersVN Example Design Rules

## Global

- Use image generation for final ad images.
- Use real people/networking/dinner photos as references.
- Every ad should read as networking within one second.
- Headline, support, CTA, and event details should stay in the central eye zone.
- Use `Da Nang` on image to avoid image generation spelling errors.
- Event venue line: `FOR YOU SteakHouse`.

## 1x1

- Size: `1080x1080`.
- Compact central stack.
- Keep text within the center 70 percent of the canvas.

## 4x5

- Size: `1080x1350`.
- Feed portrait.
- CTA should stay near the main message, not stuck to the bottom.

## 9x16

- Size: `1080x1920`.
- Story safe zones are strict.
- Keep key copy away from platform UI zones.

## 16x9

- Size: `1920x1080`.
- Logo can sit top-left.
- Text should sit in a contained center-left card/panel.
- People/networking scene should stay visible on the right.
