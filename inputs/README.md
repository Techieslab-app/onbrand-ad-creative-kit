# Inputs

Copy files from `templates/` into this folder for a real campaign:

- `brand/brand.md`
- `brand/tokens.json`
- `design-rules/rules.md`
- `hooks/hooks.csv`
- `hooks/personas.md`
- `ad-batch.yaml`
- `media/` with logo and approved reference images

The package is standardized around these roles, not exact filenames only. If a team already has a brand guide or design rules file, map it into the closest role and keep the original file too.
