# Creative QA

## Brand

- Logo matches supplied logo files.
- Colors match `tokens.json`.
- Typography direction matches `brand.md`.
- Visual style follows the brand system and avoids listed anti-patterns.

## Message

- The ad communicates the offer quickly.
- Hook matches the intended persona.
- Support copy clarifies the offer.
- CTA is visible and action-oriented.
- Localized copy is written for the local audience, not mechanically translated.

## Layout

- Text is inside safe zones.
- CTA is near the main message.
- Mandatory details are not pinned to the canvas edge.
- Ratio adaptations are intentional, not stretched.

## Image

- Image source follows the design rules.
- Approved reference library is used when required.
- Generated imagery does not invent forbidden people, objects, products, logos, or scenes.
- The image supports the hook within one second.

## Output

- Dimensions are exact.
- File naming is consistent.
- No obvious spelling errors.
- Batch has enough layout variety to avoid looking duplicated.
