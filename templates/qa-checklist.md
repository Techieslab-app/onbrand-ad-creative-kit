# QA Checklist

## Input Coverage

- [ ] Brand system was read.
- [ ] Logo files were used as references.
- [ ] Color/type tokens were followed.
- [ ] Design rules were followed.
- [ ] Hook/persona strategy was preserved.
- [ ] Reference images came from the approved media library.

## Ratio Coverage

- [ ] `1x1` outputs are exactly `1080x1080`.
- [ ] `4x5` outputs are exactly `1080x1350`.
- [ ] `9x16` outputs are exactly `1080x1920`.
- [ ] `16x9` outputs, if any, are exactly `1920x1080`.

## Brand QA

- [ ] Logo is accurate.
- [ ] Palette is accurate.
- [ ] Type direction feels aligned.
- [ ] Visual world matches the brand.
- [ ] Avoid list is respected.

## Message QA

- [ ] Headline is spelled correctly.
- [ ] Support copy is spelled correctly.
- [ ] CTA is visible.
- [ ] Mandatory details are present.
- [ ] Persona/angle still makes sense.

## Layout QA

- [ ] Text is inside safe zones.
- [ ] CTA is near the main message.
- [ ] Important info is not on the canvas edge.
- [ ] Batch has layout variety.
