# Design Rules

## Global Rules

- Final creative assets should be generated as raster images using an image generation model.
- Use supplied brand assets and reference imagery.
- Keep mandatory text inside platform-safe zones.
- Do not invent or redraw the Lovable logo.
- Use the warm light background, dark text, blue primary, and coral/pink accents.
- Keep the creative product-led: show a chat prompt becoming an app or website interface.

## Layout Lockups

- Logo position: top-left for feed assets; top safe-zone for story assets.
- Headline zone: left or center-left, not overlapping product UI.
- Support copy zone: directly below headline.
- CTA zone: below support copy.
- Mandatory detail zone: bottom safe area, optional.

## Ratio Rules

### 1x1

- Size: `1080x1080`
- Safe zone: 96 px margin on all sides.
- Preferred layouts: product UI on right or lower half, headline on left/top.

### 4x5

- Size: `1080x1350`
- Safe zone: 96 px side margin, 120 px top/bottom.
- Preferred layouts: stacked logo, headline, product UI, CTA.

### 9x16

- Size: `1080x1920`
- Safe zone: 120 px side margin, 220 px top/bottom.
- Preferred layouts: logo top, headline upper third, product UI middle, CTA lower third.

### 16x9

- Size: `1920x1080`
- Safe zone: 120 px margin on all sides.
- Preferred layouts: split headline and product UI.

## Image Rules

- Use: crisp product UI mockups, chat input, generated app preview, white/warm surfaces, subtle blue/coral/pink accents.
- Avoid: stock photos, dark hacker rooms, robots, unrelated hearts, fake code rain, crypto motifs.
- People/product/scene requirements: product interface should be the hero; people are optional and should not dominate.

## Batch Variation Rules

- Rotate layouts across: split panel, stacked product reveal, full-bleed UI crop.
- Keep consistent: Lovable palette, logo placement, short direct copy, product-led composition.
- Avoid repeated: identical UI cards, generic AI sparkle visuals, oversized decorative gradients.
